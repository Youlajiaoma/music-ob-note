## 音数

每两个相邻的键之间的音数为0.5

小二度的音数一定是0.5
0.5音数不一定是小二度


|  例子  | 音程  | 音数  |
| :--: | :-: | :-: |
| C C  | 纯一度 |  0  |
| C bD | 小二度 | 0.5 |
| C D  | 大二度 |  1  |
| E G  | 小三度 | 1.5 |
| E G# | 大三度 |  2  |
| D G  | 纯四度 | 2.5 |
| G D  | 纯五度 | 3.5 |
| G bE | 小六度 |  4  |
| G E  | 大六度 | 4.5 |
| F bE | 小七度 |  5  |
| F E  | 大七度 | 5.5 |
| C C1 | 纯八度 |  6  |

比小 还要小 0.5 叫减音程
比大 还要大 0.5 叫增音程

## 快速识别音程的方法

### 不含有升降号的两个音

#### 二三度
包含EF BC的二度三度 为大度

#### 四度（可包含 或者 不包含）所以是纯四度 和 增四度

包含EF或BC其中一个，叫纯四度
EF与BC都不包含，叫增四度

#### 五度 （一定会包含一个 可以包含两个） 所以是纯五度 和 减五度
包含EF或BC其中一个，叫纯五度
EF与BC都包含，叫减五度

#### 六度  七度（一定会包含一个 可以包含两个） 所以是大度 和 小度

任意两个白键可以组成的音程名

### 含有升降号的两个音

1. 先判断不带升降号是什么音程
2. 然后看升降号使音程变大 还是变小 把升降号算进去
3. 变大一次就增一次 变小一次就减一次 最终得到正确的的音程
## 八度以外的音程
先放到八度以内（不要改变高低顺序）判断是【什么几】度，再去还原度数。
(要注意，每 每隔一个八度，度数是+7而不是+8)

## 自然音程
就是一个自然大小调里 可以直接存在的音程 （调内音可以组成的音程）

## 变化音程
一个自然大小调里 不可以吹姐存在的音程

## 协和音程和不协和音程

### 极完全协和
纯一度 纯八度

### 完全协和
纯四度 纯五度

### 不完全协和
大小三 大小六

### 不协和
大小二 大小七 以及所有增减 倍增倍减
